# MoonLabeler Swift

MoonLabeler 的 macOS 原生移植，主界面沿用 Python **0.12.1** 的布局，并同步 Python **0.12.4** 的改动。SwiftUI / AppKit 负责窗口、画布和编辑，Swift 与原生 C/C++ 负责计算。运行无需 Python、Qt、Homebrew 或单独安装 OpenCV；应用包含所需的原生库。

Swift 版的说明、构建入口、许可和署名文件全部位于 `swift/`，与 Python 版根目录及 `docs/` 中的文档分开维护。`.build/`、`dist/`、下载的星历和 DEM 二进制文件由本目录的 `.gitignore` 排除；打包只使用本目录的说明文件。

这是面向完整功能迁移的个人版本，没有试用期限或人为功能限制。当前源码为 Swift **0.12.4**，版本号与 Python 版一致。原始标注可选择本机字体，缺少字体或字形时回退。实际验证范围见下文；0.3.x 章节记录此前的内部开发版本。

## 运行

打开 `dist/MoonLabeler Swift.app`。当前构建适用于 Apple Silicon、macOS 14 及更新版本。应用约 75 MB，按本机展开后的目录占用约为 72 MiB；已经包含约 18.7 MB 的 DE421、月球姿态与时间 / 坐标核，以及约 33.2 MB 的基础 LOLA DEM。更高分辨率 DEM 和联网参考影像会另占缓存空间。

2026-11-04 的本机体积对照：Swift 0.3.0 应用目录约 71.8 MiB，本地 Python 0.11.0 应用目录约 161.3 MiB，减少约 55.5%。本地 Python 应用已带星历，但没有内置基础 DEM；两者均未计入应用外的用户缓存。该对照不能当作 Python 0.12.1 在相同打包条件下的精确节省比例。

主窗口沿用 0.12.1 的布局：左侧月面画布，右侧“校准 / 标注 / 参考”。地名搜索位于辅助找坑和手动取点区域；没有常驻的左侧资料库。标注页的高级分组默认收起。

## 已实现的功能

- JPEG、PNG、TIFF、HEIC、FITS 读取，EXIF 方向处理、原尺寸 sRGB PNG 与可编辑文字 SVG 导出。
- JPL DE421 星历、月面姿态与拍摄地点修正；有限距离球面投影、DEM 地形投影、镜头径向畸变。
- 自动识别与独立验证、月面底图匹配、地形参考匹配、目镜后照片配准、候选坑缘检测、参考点引导识别与手动校准、镜像判定。
- 画笔、橡皮和多边形排除区域；参考点启停、重选和误差检查。
- 9,087 条内置月面地名及别名搜索，简体、繁体、英文与双语名称，着陆点，分档字号、避让排版、坑缘圈、沿地形排列名称、手工改名 / 拖动 / 隐藏、撤销与重做。
- 原始标注及六种艺术样式；高程着色、等高线、经纬网、照片估计 / 星历晨昏线、照片区域示意图与可拖动图例。
- 共享受光阈值、自动阈值恢复、独立的地名筛选和地图覆盖开关；阈值变化保留标签排版和手工编辑。
- LOLA LBL / IMG 与 NPZ 高程读取、基础 DEM 下载、区域地形模拟、NASA 同时刻参考影像、本地参考工程配准、参考图与工程保存、USGS 地名更新。
- 简体中文、繁体中文和英文界面；CPU 与可用设备上的 Metal 地形计算。

联网功能需要对应数据服务可访问。NASA 参考影像的年份范围与原版相同，目前为 2026 年。

## 工程与交互

可打开 `.moonlabel` 和 `.moonswift` 工程。`⌘S` 保存原生 `.moonswift`；“文件”菜单的“保存兼容 .moonlabel 工程…”可保存供 Python 版打开的副本。照片使用相对路径引用；移动工程时请一并保留照片。找不到照片时会提示重新选择。

导入时保留原版配准、地形修正、镜头畸变、标注编辑、隐藏状态和未知工程字段。旧工程缺少“沿地形排列名称”字段时保持原有直排方式；缺少新地图覆盖字段时保持原有覆盖。

滚轮和触控板用于画布缩放、列表与面板滚动，停在参数上也不会改值。`⌘0` 适合窗口，`⌘1` 原始大小；拖动空白处平移，按住 Cmd 拖动标签、图例或示意图，双击标签改名。Option + Cmd 拖动可调整标注指向。

## 构建与验证

需要 Xcode / Command Line Tools、Swift 5.9 或更新版本，以及 CMake。首次构建会从官方来源下载固定版本的原生依赖和科学数据；之后复用构建缓存。

```bash
cd swift
./build-app.command
```

`Native/build.command` 编译 OpenCV、libjpeg-turbo、CSPICE、ERFA 和 CFITSIO，并生成单一原生动态库。应用打包时拷贝资源、移除开发路径并执行本机 ad-hoc 签名。没有第三方 Swift 包依赖；可用 Xcode 打开 `Package.swift`。

打包先在本目录的 `.build/` 中完成，签名检查通过后再替换 `dist/` 中的应用包；不会覆盖运行中进程映射的二进制文件，也不会自动关闭编辑窗口。更新后重新打开应用即可使用新版本。

日常打开已有 `.app` 无需编译。修改源码后仍需要编译；Swift 脚本和 `swift run` 也会先编译。完成一次构建后，开发时可在 `swift/` 直接运行下面的增量构建入口，复用发布配置缓存并省去打包、资源复制和签名。修改原生 C/C++ 后先执行 `cmake --build .build/native-build --parallel 8`；需要更新 `dist/` 的独立应用时再运行 `build-app.command`。

```bash
CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache" \
SWIFT_MODULECACHE_PATH="$PWD/.build/ModuleCache" \
swift run -c release --disable-sandbox --cache-path .build/cache \
  --config-path .build/config --security-path .build/security MoonLabelerSwift
```

```bash
CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache" \
SWIFT_MODULECACHE_PATH="$PWD/.build/ModuleCache" \
swift test --disable-sandbox --cache-path .build/cache \
  --config-path .build/config --security-path .build/security
```

测试包含 0.12.1 排版位置、候选排序、字号、文字边界、曲线排字和手动 DEM 二次拟合的数值对照，以及投影、星历、镜像 / 异常参考点、文件往返、受光遮罩、导出和滚轮保护。已在真实北极、普通月面和手机照片上验证自动配准，并在实际 macOS 窗口验证打开、保存和导出；Metal 与 CPU 另做设备数值对照。

`tools/prepare-parity-fixtures.py` 仅用于开发阶段：使用原版 Python / Qt 生成对照数据，随 Swift 测试保存静态结果。它不参与应用构建或运行。

`tools/prepare-decoration-parity.py` 直接使用 Python 的 `Annotation` 与 Qt 场景，生成文字层级及坑缘引线对照。加上 `--render-native <native.moonswift> --output <目录>` 时，使用配套 `native.svg` 中的可见标注集合，在相同位置、字号及坑缘几何下绘制 Python 参考 PNG，并记录实际引线坐标。这也是开发工具，应用运行不依赖 Python。

## 与 Python 版的对齐进展

以下项目已由简化实现改为对应原版流程：

- 手动校准先做球面拟合，再使用 DEM 高程与可视坑缘中心重新拟合同一组参考点。四组 Python 数值对照覆盖镜像和两种坑缘形状；保存重开后保留地形标注落点。
- 沿地形排字保留曲线平滑、弯曲限制、候选区段选择，以及双语各自偏移曲线的弧长排布。静态几何与实际 Qt 字体排字均有数值对照，手工移动继续保留。
- 修改拍摄日期、时间或地点会清除旧配准、地形修正与参考预览；参考点修改清除旧配准。撤销和重做同步恢复对应显示，拍摄方式选择在下次识别生效。
- 候选坑缘可导出带 UTF-8 BOM 的 CSV。独立 DEM 预览支持缩放、平移、保存和匹配；不足 64 个地形采样点时拒绝不可靠的参考匹配。导出的参考工程不携带原照片的参考点或标签。
- 计算设置提供设备状态、CPU / 自动选择、失败回退与环境变量覆盖；完整帮助覆盖自动、辅助、手动、标注和 DEM 流程。艺术预设默认不透明度与着陆点颜色已按原版修正。
- 0.3.1 修复实机模拟生成时 CSPICE 先申请读写内置星历而阻塞的问题：输入内核直接只读打开，打包数据设为只读；与 Python 星历的数值对照仍通过。预览窗口固定最小可用尺寸，区域搜索同步渲染中心、按直径排序并沿用原版默认搜索；更改模拟参数会清除旧预览，内置高程会明确显示为可用。
- 0.3.2 修复放大图像越出画布、遮住说明栏的问题。缩放与拖动限制在画布内，保存对话框明确限定 PNG。预览缩放、拖动、保存，以及 Python 版读取实际导出的参考工程均已完成实机验证；保存保持原始模拟尺寸。
- 0.3.3 修正日期编辑文字上移、填满位数不跳格的问题。日期与时间各自保留共享草稿，避免输入 2 月时把尚未修改的 31 日自动滚到 3 月；无效日期不能启动识别。打开照片保留已输入的 UTC 与地点，识别和手动校准先提交编辑再读取拍摄条件。
- 0.3.3 对齐 Python 识别成功后的直径筛选：按照片比例降低初始的 40 km 门槛，并清除旧配准的地形采样与坑缘缓存。`0708.jpg` 在 2026-07-08、默认 UTC 15:00 下获得 459 个图像对应点，回到虹湾北部区域；不是截图中错误的南部地名。
- 0.3.3 示意图使用拍摄时实际观测到的月球视角，不再朝照片中心转动整个月球。取景轮廓改用二值外轮廓，隐藏的极点只显示方向箭头；去除 Earth 标记，并按 Python 0.12.2 的共享 SVG 卡片对齐配色与文字。几何对照覆盖北部取景框、极点可见性和中心经纬度，画布与 PNG / SVG 共用同一套卡片。
- 0.3.4 恢复致谢窗口中的原作者、LTVT、10deg、Evan Tsai、sothic、检测方法和数据来源信息及链接，并可在应用内阅读完整 Swift 致谢与第三方声明。新打开照片回到校准页。参数数值框采用统一紧凑宽度，单位放在框内，上下微调按钮垂直居中；滚轮继续滚动外层面板。

## 0.3.5 补齐的功能差异

- 自动识别结果：回填真实候选中心作为自动参考点，优先显示已匹配的主要环形山。重新识别替换旧自动点，保留手动点及自动点的停用状态；旧自动点不再作为独立验证依据。参考点和匹配名称、候选数量可保存、重开和供 Python 读取。`0708.jpg` 从新工程识别得到 459 个图像对应点，回填 11 个自动参考点，其中 4 个主要环形山获得显示优先级。
- 候选坑缘检测：半径范围对齐为 3–4000 px，灵敏度 0–100，候选上限 1–500、默认 80。半径、灵敏度、上限与视野选项随原生及兼容工程保存、恢复；新照片使用默认值，修改参数提示重新检测。
- ICC 色彩管理：原始识别像素与 sRGB 显示副本分离，支持 Display P3 / Adobe RGB、灰度与 CMYK。画布、PNG / SVG 使用显示副本，艺术样式先对显示副本去色；星历、DEM、配准与原始样本不变。16 组 Python 全像素对照覆盖 JPEG / PNG / TIFF、RGB / 灰度 16 位 TIFF、CMYK 及全部 EXIF 方向变换；另有实际画布与艺术底图回归。CMYK JPEG 的 Adobe 反向编码也已按原始样本转换。

## 0.3.6 补齐的操作差异

- 地形类别明确区分“全部”和未选择任何类别。取消“全部”不再自动选中环形山；重新勾选再取消“全部”保留已选类别，未知类别仍可见、可选。原生和兼容工程均保留空列表含义，旧原生工程仍按原来的空列表表示全部。着陆点保持独立，手工标签的显示优先级不绕过类别及直径筛选。
- 辅助找坑可以直接点击照片中的候选中心选择编号。候选地名与手动补点分别搜索、选择；候选搜索只列环形山，精确名称优先，留空时不预选无关地名。换候选、修改搜索或移除候选会清除旧地名选择；月球背面的地名不能确认。检测完成自动回到辅助找坑，底部可直接展开已确认参考点。
- 校准参考点只在校准页显示，改用原版十字、编号及偏差虚线；辅助找坑时可通过“参考点与配准”展开控制标记显隐。切换工作区或关闭取点分组会结束取点、候选重选与未完成的蒙版笔画。新照片收起校准分组并回到面板顶部；画笔默认直径 80 px、范围 2–2000 px，并有“完成”按钮。
- 隐藏、恢复显示、改名、重新排布和重置手工编辑会更新实际标签排版；恢复显示的标签获得与 Python 相同的优先级，列表注明“避让收起”。这些操作复用现有地图、受光缓存、示意图及艺术底图，同时保留尚未应用的筛选和样式，不会借标签操作应用其他待生成设置。新显示的类别数量和候选确认等英文提示可使用原版格式化翻译。
- 打开照片及工程现在纳入可取消任务。取消或关闭窗口会保留原工程；即使 ImageIO 的文件读取尚未返回，编辑器也能结束等待、重试或关闭，迟到的旧读取结果不会覆盖新照片。测试使用实际窗口关闭及受控延迟读取覆盖取消、重试和迟到结果。

## 0.3.7 画布交互与清晰度

用 `09301712.jpg` 的同一中世纪风工程重放连续平移，包含高程、等高线、受光覆盖和文字。画布为 1400 × 900 逻辑点、2800 × 1800 像素，先预热一次，再记录 12 帧；以下是本机发布构建的 CPU 重绘耗时，不能直接当作实际屏幕帧率：

| 场景 | 中位数 | 第 90 百分位 |
| --- | ---: | ---: |
| 平移，优化前 | 261.51 ms | 263.23 ms |
| 平移，构建 14 | 11.17 ms | 11.21 ms |
| 连续缩放，逐次重建缓存 | 362.43 ms | 392.86 ms |
| 连续缩放，构建 14 | 18.98 ms | 19.14 ms |

连续缩放时复用当前预览，最后一次输入后 120 ms 按实际显示倍率重新绘制照片、地图与文字。Retina 屏幕使用完整的用户坐标到设备像素变换，包含屏幕 backing scale；不再用缺少屏幕倍率的 CTM 生成低分辨率缓存。放大后的缓存分块与缩放预览分开维护，停止缩放后恢复清晰绘制。第一次绘制、首次进入新分块或修改显示内容仍需要生成缓存，耗时随图层和照片而变。

## 0.3.16 TIFF 对齐、读取内存与导出取消
