# MoonLabeler UI 重构设计说明

日期：2026-10-11 · Zcode 原始负责范围：`moonlabeler/ui/**`、`tests/test_ui_*.py`、`docs/ui/**`
（原始交付遵循 `UI_HANDOFF.txt`；随后 Codex 完成业务接入和手动校准流程改进，见下文。）

## 1. 目标与原则

- **照片优先**：照片画布是窗口的主体和视觉中心，界面色板向照片让位。
- **一条主线**：打开照片 → 选拍摄日期 → 自动识别 → 标注微调 → 导出，
  界面按这条动线组织，专业参数渐进展开。
- **诚实呈现**：不改动任何识别/配准文案与数值；状态文字仍由业务层给出
  （含精度限制说明），UI 只负责可读性。

## 2. 布局结构

```
┌────────────────────────────────────────────────────────────┐
│ 工具栏  [打开照片][打开工程][保存工程] │ [导出PNG][导出SVG] │ [适合窗口]   打开示例 帮助 致谢 │
├─────────────────────────────────────────────┬──────────────┤
│                                             │ MoonLabeler  │
│                 照片画布                     │  (检查器面板) │
│          （拉伸优先级 1，占主要宽度）          │ 校准 | 标注 | 参考 │
│                                             │  ┌──────────┐ │
│  ─ synthetic-moon.png      1,600×1,450 px ─  │  │ 滚动内容  │ │
│                                             │  └──────────┘ │
│                                             │ [编号→地名·确认]│
├─────────────────────────────────────────────┴──────────────┤
│ 状态栏                                                      │
└────────────────────────────────────────────────────────────┘
```

- **画布在左、检查器在右**（原为侧栏在左）。macOS 检查器惯例，照片贴主视区，
  左侧不再有固定占宽；splitter 不可折叠，画布持拉伸因子。
- **检查器三页**（页签索引不变：0=校准，1=标注，2=参考）：
  - **校准**：拍摄条件（紧凑表单）→ 自动识别（主按钮 + 状态）→
    “辅助找坑与参考点”（**默认折叠**）：候选检测 → 名称确认 → 参考点与配准；
    手动补点在同页的折叠入口里。业务层通过
    `ui_set_manual_section_expanded(True)` 打开辅助区。
  - **标注**：筛选与数量 → 名称与文字 → 排版选项 → 应用与标签列表
    （重新生成标注为主按钮，列表拉伸填充）。
  - **参考**：影像匹配 / DEM 模拟（DEM 渲染参数折叠，默认收起）。
- **当前候选与确认按钮固定在校准页页脚**（滚动区之外）：编号、坐标和选定地名
  始终可见；候选列表、搜索框和地名结果在同一滚动页里按顺序排列。
  页脚只占约 97px，不再挤压滚动区。可见性仍由
  `app.show_crater_overlays()` 控制（校准页 + 辅助区展开 + 手动补点收起）。
- 分段采用**扁平标题**（QGroupBox 去边框），层级靠字号/颜色/留白表达，
  不再是连续大框。

## 3. 点击逻辑（交互呈现层）

全部为纯 UI 回调，`ui_` 前缀，业务信号连接保持原样：

| 交互 | 行为 | 实现 |
| --- | --- | --- |
| 搜索框回车 | 选中首个结果（地形点/疑似坑/DEM 三处） | `ui_select_first_*`，只改选择状态，业务动作仍需显式点击 |
| Esc（画布聚焦时） | 退出取点/复核模式 | `ui_cancel_pick` → 复用 `cancel_pick()`，幂等 |
| 折叠开关 | 检测设置、DEM 渲染参数渐进展开 | `ui_collapsible`，收起时信号保持连接，数值仍可同步 |
| 工具栏分组 | 文件/导出/视图靠左，帮助类右对齐 | 弹性占位 `QWidget` |
| 下拉弹层加宽 | 弹层宽度＝max(最宽条目, 组合框宽度)，长中文条目不再截断 | `WidePopupComboBox`，全部下拉框统一；当前项以高亮表示（不再有原生勾标记） |
| 手动校准折叠 | 默认收起，标题栏为展开入口；进入取点（pick_button 追加监听）或业务层显示确认条/取消按钮（Show 事件过滤）时自动展开 | `ui_set_manual_section_expanded(bool)` 公开接口 + `ui_reconcile_confirm_bar` 收起联动 |
| 时间标题按需摘要 | 折叠时标题带当前 UTC 时间；展开后只留“具体时间”，不再重复显示 | `sync_capture_time` 同步编辑框后调用 `ui_update_time_summary` |
| 日期与时间输入 | 年/月/日、时/分独立输入，满位自动前进；旧工程秒值保留 | `CaptureField` 与隐藏时间模型同步 |
| 辅助找坑 | 按“选择候选坑 → 选择地名 → 确认”排列；输入和滚动期间，底部持续显示当前编号和选定地名 | `ui_refresh_crater_review` 从当前选择读取状态，不另存业务选择 |
| 复核区按内容分配空间 | 空列表隐藏；候选显示最多三行，地名结果最多两行，更多条目可在列表内滚动 | `ui_refresh_crater_review`，由业务刷新和窗口调整调用 |
| 次要候选操作 | 重选中心、移除、CSV 导出和全部轮廓开关放进“更多操作”，默认收起 | `ui_crater_tools_toggle`，原有业务控件和信号保留 |
| 滚动定位 | 仅进入辅助找坑或检测完成时定位操作位置；打字、结果增减、窗口变化不主动重置位置 | 窗口所属单次定时器；移除滚动区 Resize 触发的反复定位 |
| 辅助页高度 | 仅保留一个辅助页，展开参考点/手动补点时使用自然高度 | Qt 布局与单次滚动定位 |
| `QTabBar.setDrawBase(False)` | 去掉子页签多余基线 | 纯样式 |

保留的既有入口与契约（`tests/test_ui_layout.py` 逐项锁定）：
`workspace_tabs` 页签索引、`registration_tabs`/`crater_tab` 对象身份、
`self.scroll` 包含 `feature_search`（`nasa_failed` 滚动定位依赖）、
全部 `self.<控件名>` 与信号连接、日期 UTC 15:00 默认值、
"调整后需点击重新生成标注"的延迟应用模式、后台忙碌禁用
（`sidebar`/`toolbar`/`canvas` 由 app.py 统一禁用，页脚操作条是其子树）。

## 4. 主题

`theme.py`："天文台深色"。控件默认透明、按表面显式着色，避免全局背景
规则在面板上产生异色矩形。

- 画布周围近黑（窗口底 `#131821`），检查器面板 `#171d28`；
- 暖金 `#d9a96c` 仅用于：主按钮（自动识别/用参考点配准/重新生成标注/
  检测疑似坑中心/确认地名/生成模拟图/打开照片）和子页签选中下划线；
- **勾选控件统一为朴素样式**（用户定稿）：未选中＝空框，选中＝同一暗底框内
  一个浅色对勾，无填充无边框变色（`assets/check_dark.png`，程序绘制的
  本地图标）；`QCheckBox`、标签列表、参考点表共用同一套指示器；
- 一级页签＝分段样式，二级页签＝下划线样式，层级一眼可辨；
- 状态文字统一 12px 三档灰（`noteLabel`/`statusLabel`/`statusStrong`），
  由 objectName 挂接，不写内联样式；
- 无新增依赖、无网络字体；唯一本地资源为程序绘制的对勾图标
  `assets/check_dark.png`。

## 7. 已知限制 / 未完成项

1. **已完成接入**：候选轮廓开关改用独立的 `crater_overlay_toggle`，不再干扰导出坑缘圈；补充真实控件回归验证。
2. 空候选与空地名结果不占位；候选列表高度受限，条目多时在列表内滚动。
3. 检查器最小宽度 340px：极端窄窗口下部分提示文案换行较多，但无截断。
4. 已补充 macOS Cocoa 原生验证：语言下拉菜单、日历弹层、普通窗口、最大化和三点校准流程。原始 offscreen 截图仍保留作交付记录。
5. 进入取点时自动聚焦画布，可用 Esc 取消；另有明确的取消按钮。切换工作页也会退出取点。

## 8. 接入后的手动校准流程

- 参考点用“地名 + 照片位置”解释；三步提示、当前地名和有效点数随操作更新。
- 添加参考点无需先算几何；“完成校准并生成标注”会自动计算，成功后进入标注页。默认至少三点，高级镜像模式允许两点。
- 每次取点结束都会退出拾取；改选结果、切页、Esc 或取消按钮也会退出，防止旧地名被误用。
- 表格编号对应画布固定屏幕大小的十字/编号；同名取点更新位置，双击表格可重选。
- 辅助找坑搜索结果下方提供“查看参考点（点数）并继续配准”，返回取点表和辅助配准入口。
- 换选候选坑后取消上一个地名的选择，需重新确认；重选同一坑的中心保留所选地名。
- 候选轮廓与导出坑缘开关已分离。
- 新增 `tests/test_manual_workflow.py`：实际控件取三点后延迟计算几何、生成标注；取消/换名/重选；下载失败保留参考点。

`native-*.png` 为此前的 macOS Cocoa 真机检查截图，`preview-*.png` 为 offscreen 布局截图，包含 Zcode 交付与 Codex 接入后的检查。均只使用合成示例。仓库首页截图 `../moonlabeler.png` 为此前整合后的原生界面。

## 9. 具体时间（默认折叠）

拍摄日期下显示“具体时间 · UTC HH:mm:ss”；展开后编辑时分，保留默认或工程原有秒值，并可恢复默认 15:00:00。展开标题只显示“具体时间”。收起只改变显示，更换日期也保留时间。旧工程加载会同步显示精确时间；实际修改才会使配准失效。

已接入 Zcode 后续的统一复选框样式，并将本地对勾图标列入安装资源。

## 10. 文案精简

删除副标题、空白画面口号和重复说明。常驻提示只保留短状态、手动取点三步和点数；配准细节、操作补充与模型限制放入悬停提示或帮助。识别、校准、导出完成后直接显示结果。原生校准页截图见 `native-calibration.png`。

## 11. 辅助找坑的选择与确认（0.5.5）

地名结果显示由业务刷新统一同步，因此更新目录、加载工程等直接调用搜索回调的路径也会显示实际结果。搜索不自动认定地名，仍需点击或回车选择后确认。列表高度和页签高度调整仅影响显示，不触发检测、配准或标注计算。

固定页脚显示候选编号、位置和选定地名。即使候选列表失去焦点或滚出视野，仍可核对确认对象。地名结果与候选列表不再放在固定页脚里。确认按钮带当前候选编号；加入后显示编号和地名，并更新参考点数量。

`tests/test_ui_integration.py` 覆盖普通窗口与最小窗口的检测/确认入口、焦点和滚动变化时的候选状态、换坑时取消旧地名、单项结果鼠标选择、重选中心后确认到正确位置、搜索结果变化不重置滚动，以及连续输入时分及原有秒值保留。


## 12. 同页参考点流程与分段时间输入（0.5.6）

取消独立“已知地名取点”页签；检测、确认地名和“参考点与配准”位于同一滚动页。直接在照片上取点放进默认折叠的“手动补点”，用于补充漏检坑或其他地形。确认候选后点击“查看参考点”展开表格，可用一两个点尝试自动配准；三个分散点可做纯手动校准。失败不再切换取点模式。

日期使用独立年/月/日框，时分也分开，输入满位后自动前进。隐藏的 `date` 和 `capture_time` 控件仍作为旧 API 的时间模型；旧工程秒值保留。打开新照片回到“校准”并收起辅助区、检测设置、参考点及手动补点，当前时间不变。侧栏只保留一个辅助页，自然高度随折叠内容变化；明确点击查看参考点时，待展开布局完成后滚入自动配准按钮，普通输入/窗口调整不触发滚动。
