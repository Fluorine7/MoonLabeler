MoonLabeler：给 zcode 的 UI 改造边界

工作目录：/Users/fluorine/Downloads/LunarAnnotation
目标：重做桌面应用的信息层级、布局、侧栏、工具栏、间距和交互呈现，让照片成为主体。可以大胆优化布局，不只是换颜色和字体。继续使用 PySide6 原生界面。

当前代码已拆分：
- moonlabeler/ui/window.py：WindowUiMixin，构建工具栏、侧栏、检测控件；已由 MainWindow 接入。
- moonlabeler/ui/theme.py：应用界面的 STYLE 样式；已由 MainWindow 接入。
- moonlabeler/ui/__init__.py：UI 包。

zcode 独占的写入范围：
- moonlabeler/ui/**（可添加组件、主题和本地图标等资源）
- tests/test_ui_*.py（仅新增自己负责的 UI 测试，不修改现有测试）
- docs/ui/**（设计说明、截图、方案）

Codex 负责，其余文件只读：
- moonlabeler/app.py：主窗口生命周期、业务回调、异步工作、画布与标注图元
- project.py、geometry.py、registration.py、identification.py、atlas.py、limb.py、terrain*.py、craters.py、layout.py、sources.py
- 数据目录、依赖、启动脚本、版本号、README、许可证、已有测试
- moonlib-core/** 是朋友提供的本地研究代码，勿改动或纳入公开提交。

接口约定：
1. 保留 WindowUiMixin 及 build_toolbar(self)、build_sidebar(self)、build_crater_controls(self, page) 的签名。可以提取内部组件或新增纯 UI 辅助方法，不覆盖 app.py 已有方法。
2. 保留现有 self.<控件名>，以及业务代码调用的控件类型/方法、信号连接。新增控件和纯 UI 回调使用 ui_ 前缀，避免与业务属性重名。
3. 保留 workspace_tabs 的页面索引：0=校准，1=标注，2=参考；保留 registration_tabs 与 crater_tab 的对象身份契约。可自定义外观及页面内部排布。
4. 日期仍只显示年月日，新选日期默认 UTC 15:00；旧工程加载保留原始时间。不要在 UI 重写日期、天平动、配准逻辑。
5. 标签设置修改后只标记待应用，点击“重新生成标注”才执行；不要改成每次控件变化立即重算。
6. 画布、标签避让、坑缘圈坐标、导出字号及 PNG/SVG 的逻辑归 Codex。界面重排不能修改项目参数、生成假识别结果、改变文件格式或复制另一套业务状态。
7. 保留全部现有功能入口；可折叠低频选项。保持照片缩放/平移、拖入照片、保存/导出、后台忙碌禁用状态和错误反馈正常。不能 disconnect() 清空业务信号。
8. 为避免同时写同一文件，如必须修改范围之外的接口，请在 docs/ui/integration_requests.txt 写明具体需求，由用户转给 Codex 接入；不要直接改 app.py。
9. 同目录协作，不执行 git reset/restore/clean/checkout/stash、全仓库格式化、git add .、提交、推送或依赖升级。不要删除、覆盖或整理另一方的未提交修改。最终由 Codex 合并检查与提交。

设计要求：
- 照片优先；减少左侧占宽和连续大框，让主操作清晰。
- 提高布局层级和空间利用率；低频专业参数可渐进展开。
- 适配 macOS 最大化与普通窗口，中文下拉框/表单不截断。
- 识别进度与结果清楚可读；不能用“成功”掩盖未知或精度限制。
- 不引入 Web 前端、网络字体或大型依赖，不打包应用。
