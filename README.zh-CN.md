# MoonLabeler 使用说明

**0.9.4** · Fluorine Zhu · [English](README.md) · [更新记录](UPDATE_HISTORY.md)

为整月或局部月面照片配准、编辑地名，并导出 PNG / SVG。界面支持简体中文、繁体中文和英文。

## 下载与打开

0.9.4 暂仅更新源码，安装包仍为 0.9.3。

| 系统 | 下载 | 打开方式 |
| --- | --- | --- |
| macOS 14.4+，Apple Silicon（M1 或更新） | [macOS ZIP](https://github.com/Fluorine7/MoonLabeler/releases/download/v0.9.3/MoonLabeler-0.9.3-macos-arm64.zip) | 解压后打开 `MoonLabeler.app`，也可拖入“应用程序” |
| Windows x64 | [Windows ZIP](https://github.com/Fluorine7/MoonLabeler/releases/download/v0.9.3/MoonLabeler-0.9.3-windows-x64.zip) | 完整解压后运行 `MoonLabeler.exe`，保留旁边的 `_internal` 文件夹 |

安装包自带运行环境、FITS 支持和离线星历。Mac 包采用临时签名，首次打开若被拦截，可在“系统设置 → 隐私与安全性”中允许运行；不支持 Intel Mac。

## 自动识别并标注

1. 打开照片，核对拍摄日期与 **UTC 时间**。启动默认 UTC 15:00，展开“具体时间”可修改；北京时间减 8 小时。拍摄地点可选，不填使用地心近似。
2. 点击 **“自动识别并标注”**，成功后进入标注页。
3. 调整地形类别、最小直径、数量、语言、字号等，点击 **“重新生成标注”** 应用。
4. 按住 **Cmd（macOS）/ Ctrl（Windows、Linux）** 拖动标签，双击修改文字。
5. 保存 `.moonlabel` 工程，或导出原尺寸 PNG / 可编辑 SVG。导出沿用照片文件名，PNG 转换为 sRGB。

普通拖动平移画面；滚轮缩放画布或滚动面板，停在参数上也不会改值。“打开示例”可体验编辑流程，示例为合成图。

WinJUPOS 文件名可自动导入 UTC。例如 `2026-08-31-2137_7-Moon.tif` 对应 **21:37:42 UTC**，末位表示十分之一分钟。加载工程时使用已保存的时间，其他文件名需自行核对拍摄时间。

源码首次识别需下载约 20 MB 星历；高程匹配和地图图层另需约 33 MB LOLA 数据，缓存后可离线使用。照片在本机处理。

## 识别失败时

先核对时间、拍摄方式和清晰度。相机直拍选择“相机直拍”，手机经目镜拍摄可选“目镜后”。仍失败时，使用以下参考点流程。

### 疑似坑中心检测

在“校准 → 辅助找坑与参考点”检测候选，选中后核对坑中心；需要时“重选中心”。搜索并选中对应地名，点击 **“确认地名，加入参考点”**。输入名称后需选择结果，Enter 可选首项。

### 参考点辅助自动配准

确认一两个已知点后，点击 **“用参考点自动配准”**。顶部“自动识别并标注”也会优先使用这些点。失败时保留参考点，可继续补点。

### 手动校准：局部与整月照片

展开“手动补点”，搜索地名并点击取点按钮，在照片中点击同一个坑的完整坑缘中心。添加 **3–6 个分散、不共线的点**，再点击 **“按参考点手动校准”**。

不要用亮斑或阴影中心代替坑中心。Esc 取消取点；双击参考点行可重选位置，取消“使用”可停用该点。配准后检查表中的偏差及已知地形。

## 标签与导出

- 默认最多 200 个标签；避让空间不足的条目会显示“避让收起”，可减少数量或手动调整。
- 字号按照片短边分大、中、小三档，默认 **1.8% / 1.5% / 1.2%**。“字号递减”设为 0 可统一大小。
- 重新生成标注会保留手工文字和位置；“重新自动排布标签”会清除手工位置。
- 大坑可选择椭圆或坑缘轮廓。着陆点可单独开启，包含阿波罗与嫦娥任务。
- 工程保存配准、样式和编辑；PNG 与 SVG 使用当前已应用的设置。SVG 保留可编辑文字、网格和等高线。

## 可选艺术样式与地图图层

展开“标注 → 艺术与地图图层”，选择后点击 **“应用样式与图层”**。

切回 **“原始标注”** 会一并关闭经纬网、高程、等高线、晨昏线和受光覆盖，应用一次即可恢复，无需逐项取消。需要时仍可单独启用地图图层；原始文字设置和手工编辑保留。

| 选项 | 效果与设置 |
| --- | --- |
| 中世纪风 | 古航海地图配色、衬线地名和弧形大地名；移到月盘外的弧形文字自动改为直排 |
| 旷野地形图 | 褐色分层、深色等高线和浅色地名 |
| 月面经纬网 | 10° / 15° / 30° 间隔 |
| 高程着色与等高线 | 需要 LOLA DEM；等高距默认自动，也可手动指定，缩放画面不会改变间距 |
| 晨昏线 | “照片估计”为近似虚线；“工程时间”为理论实线，需要准确时间 |

艺术主题先将显示底图去色，切回原始标注恢复彩色。艺术标签的定位辅助线只在 Cmd / Ctrl 拖动时显示，不会导出。

高程图例也可按住 Cmd / Ctrl 拖动；位置随工程保存，PNG / SVG 使用相同位置。

图层首次应用后，不透明度和受光阈值可实时调整：拖动滑块，或在数字框输入后回车、移开焦点。“自动”恢复照片估计阈值。地图受光覆盖采用柔和过渡，关闭后覆盖全部有效月面；地名和晨昏线独立控制。

高程表示相对月球参考球面的高度，基础数据采样约 1.9 km。晨昏线与地图颜色均为参考，不能据此推断精细坑壁或真实局部阴影。

## 离线局部模拟图

在“参考”页下载或导入 LOLA DEM，选择区域与光照参数，生成局部地形参考。导入 `.LBL` / `.IMG` 时将两个文件放在同一目录；也支持带 `height_km`、`north`、`west`、`pixels_per_degree` 的 NPZ（高度单位 km，行从北向南、列向东，缺测用 NaN）。

顶部“计算设置”可选自动或仅 CPU。GPU 只用于高程阴影参考，不可用时回退 CPU；源码安装方法见[项目主页](README.md#source-installation)。

## 从源码打开

需要 Python 3.12+ 和 C++ 编译器。macOS 安装 Xcode Command Line Tools 后运行：

```bash
git clone https://github.com/Fluorine7/MoonLabeler.git
cd MoonLabeler
./start-mac.command
```

Windows / Linux 安装、FITS 与 GPU 可选组件见[源码安装](README.md#source-installation)。首次安装或更新使用 `pip install .`，以构建应用所需的原生模块。

## 模型边界与来源

自动识别可能受时间、畸变、阴影和清晰度影响；坑缘圈是投影参考，拟合偏差不等于绝对定位精度。着陆点表示公开坐标位置。近月缘区域和低分辨率 DEM 需要额外核对。

地名来自 USGS / IAU，中文优先采用 LPND；高程来自 LOLA，星历来自 JPL DE421。贡献者与数据来源见[致谢](ACKNOWLEDGEMENTS.md)，代码采用 [GPL-3.0-or-later](LICENSE)，第三方条款见[许可声明](THIRD_PARTY_NOTICES.md)。
